# SkyBrief

SkyBrief is a simple weather dashboard built with HTML, CSS, and JavaScript. It uses the Open-Meteo public REST API to search for a city and display its current temperature, humidity, and wind speed.

## Features

- Search weather by city name
- Displays temperature, humidity, and wind speed
- Uses JavaScript Fetch API
- Handles loading and error states
- Uses `textContent` for safer data rendering
- Responsive and simple user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo REST API

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter a city name and click **Search**.
